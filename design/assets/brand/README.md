# DDoToRo 브랜드 에셋

확정 마크는 **ㄸ · 먹 + 벽돌 · 라운드**다. 시안과 근거는 `brand-mark-ddieut.html`에 있다.

## 파일

| 파일 | 쓰는 곳 |
|---|---|
| `mark.svg` | **주 마크.** 밝은 바탕 위 어디든 |
| `mark-solid.svg` | 한 색만 되는 자리 — 1도 인쇄 · 자수 · 각인 · 워터마크 |
| `mark-mono.svg` | 흑백 문서 · 팩스 |
| `mark-reverse.svg` | 먹·벽돌처럼 어두운 바탕 위 |
| `favicon.svg` | 브라우저 탭 (벽돌 바탕 + 종이색 ㄸ) |
| `app-icon.svg` | 512×512 앱 아이콘 |
| `og-image.svg` | OG 이미지 **원본** — 그대로 배포하지 않는다(아래 참고) |

## 색

```
먹      #1B150D   oklch(20% 0.018 70)    --ink
벽돌    #9A5048   oklch(52% 0.10 28)     --accent
종이    #F9F8F5   oklch(98% 0.004 95)    --paper
램프4   #CA6E5D   oklch(64% 0.120 32)    --p4
```

에셋 SVG는 hex로 굳혀 두었다. 파비콘·OG는 브라우저 크롬이나 외부 크롤러가 렌더하므로
`oklch()`나 CSS 변수를 넣으면 색이 빠질 수 있다. **제품 화면 안에서 쓸 때만 토큰을 참조한다.**

## 형태 규격

```
viewBox        0 0 32 32
각 ㄷ          11.6 × 20
획 두께        3.6
모서리·획 끝   round (반지름 1.8 = 획 두께의 절반)
두 획 사이 틈  3.6 — 획 두께와 같다. 이 비례를 바꾸지 않는다
```

가로획이 12.4 / 27.6에서 끊기는 이유는 둥근 캡이 1.8을 더 뻗어 원래 폭 14.2 / 29.4에
정확히 닿게 하기 위함이다. **캡을 butt로 바꾸면 마크가 짧아진다.**

## 운용

- 여백은 사방으로 획 두께 1개분(마크 폭의 약 11%)
- 최소 크기 16px. 그 이하가 필요하면 `favicon.svg`(바탕 있는 버전)를 쓴다
- 기울이기 · 투명도로 흐리기 · 시스템 밖의 색 · 획 두께 변경 · 틈 넓히기 전부 금지
- 사진 위에 얹지 않는다. 얹어야 하면 바탕 있는 버전을 쓴다

## Next.js 적용

App Router는 파일 이름만으로 자동 인식한다.

```
web/app/icon.svg          ← favicon.svg 를 복사
web/app/apple-icon.png    ← app-icon.svg 를 180×180 PNG로 변환
web/app/opengraph-image.tsx
```

**OG는 SVG를 그대로 쓰지 않는다.** 대부분의 SNS 크롤러가 SVG를 OG 이미지로 받지 않는다.
`og-image.svg`는 레이아웃 원본이고, 실제 배포는 `opengraph-image.tsx`에서 PNG로 생성한다.
그때 Hahmlet · IBM Plex Sans KR 폰트를 함께 로드해야 서체가 살아난다.

헤더의 워드마크(마크 + `DDoToRo`)는 이미지가 아니라 **HTML로 조판한다.**
SVG에 텍스트를 넣으면 폰트가 없는 환경에서 깨진다.
