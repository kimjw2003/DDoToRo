# DDoToRo 디자인 토큰 v2

2차 설계에서 새로 정한 서체·색 체계. `assets/tokens.css`가 구현체이고 이 문서는 요약이다.
**대상은 데스크톱 웹이다** — 모바일은 데스크톱 확정 후로 미뤘다.
1차 `DESIGN.md`의 색·서체 절을 이것으로 대체한다. (설계 명제·지도 표현·문구 규칙은 1차 문서가 여전히 유효하다.)

## 색

```css
--bg:      oklch(98% 0.004 95);    /* 화면 바탕 */
--surface: oklch(100% 0.002 95);   /* 패널·카드 */
--fg:      oklch(20% 0.018 70);    /* 본문·먹선 */
--muted:   oklch(48% 0.012 70);    /* 보조 텍스트·라벨 */
--border:  oklch(90% 0.006 95);    /* 1px 구분선 */
--accent:  oklch(52% 0.10 28);     /* 주 버튼 (화면당 최대 2회) */

--hint:       oklch(56% 0.012 70);
--border-str: oklch(82% 0.008 95);
--sunken:     oklch(96% 0.005 95);
--accent-ink: oklch(44% 0.11 28);
```

### 가격 램프 (분위수 5분할)

```css
--p1: oklch(95% 0.022 48);   /* ~ 21,300원/㎡ */
--p2: oklch(88% 0.055 42);   /* ~ 42,400 */
--p3: oklch(78% 0.092 38);   /* ~ 77,100 */
--p4: oklch(64% 0.120 32);   /* ~ 156,000 */
--p5: oklch(46% 0.110 28);   /* 156,000 ~ */
--p0: oklch(92% 0.004 95);   /* 정보 없음 — 45° 사선 해치 */
```

- 1차의 초록 램프를 **점토·벽돌 계열로 교체**했다. 이유: VWorld `Base` 타일의 산림 초록과 램프가 같은 색상이라 z13~14에서 필지와 지형이 섞였다. 벽돌 계열은 배경의 누런 육지·초록 산림·파란 물 어디와도 겹치지 않는다.
- 강조색은 램프 최상단(`--p5`)과 같은 색족이다. 화면에 색 이야기가 하나만 존재하게 만드는 장치다.
- 신규 카테고리(지하철·공공시설·뉴스)에 **색을 배정하지 않는다.** 1.7px 단선 아이콘으로 구분한다 → "채도는 가격만" 원칙이 유지된다.
- 정보 없음은 색이 아니라 사선 해치. 색을 하나 더 늘리지 않는다.
- 경고·주의를 노랑/빨강으로 칠하지 않는다. `--border-str` 테두리 박스 + `--muted` 텍스트.
- 그라디언트·글로우 금지. 그림자는 주 버튼의 1px 하단 입체에만 쓴다.

## 서체

```css
--font-display: 'Hahmlet', 'Noto Serif KR', 'Apple SD Gothic Neo', serif;
--font-body:    'IBM Plex Sans KR', 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif;
--font-mono:    'IBM Plex Mono', ui-monospace, Menlo, monospace;
```

| 역할 | 서체 | 교체 전 |
|---|---|---|
| 표제·지번·금액 | Hahmlet 400/500/600 | 나눔명조 |
| 본문·라벨·버튼 | IBM Plex Sans KR 400/500/600 | Pretendard |
| 고유번호·배지·아이브로 | IBM Plex Mono 400/500 | (없음) |

명조를 쓰는 곳은 **총액 · 지번 · 페이지 제목** 세 군데뿐이다. 나머지 숫자는 Plex Sans + `tabular-nums`.

### 타입 스케일

| 용도 | 크기 | 굵기 | 자간 |
|---|---|---|---|
| 공시지가 총액 | 40px | 500 | -0.025em |
| 페이지 제목 | 30px | 500 | -0.02em |
| 지번 | 22px | 500 | -0.01em |
| 섹션 제목 | 17px | 600 | 0 |
| 본문·탭·값 | 16px | 400 | 0 |
| 라벨·단위·안내 | 14px | 400 | 0.012em |
| 아이브로(라틴 대문자) | 14px | 500 | 0.09em |

- **14px이 하한이다.** 1차 지침은 하한을 선언하고도 단위·힌트에 13px을 썼다. 전부 14px로 올렸다.
- 굵기 400/500/600 세 단계. 700 금지.
- 본문 `line-height: 1.7`, 30px 이상 표제는 1.05~1.15.
- 라틴 대문자에는 `letter-spacing: 0.09em`을 반드시 붙인다.

## 상세 패널 구조

```
┌─────────────────────────────┐
│ [실루엣 88] 읍면            × │  ← 고정. 스크롤되지 않는다
│             지번 22px 명조   │
│ 3억 2,181만원  [2026년 공시] │
│ ㎡당 194,800원 · 평당 …      │
├──────┬──────┬───────────────┤
│ 땅 정보│ 시세 │ 주변          │  ← 탭 50px, 선택은 2px 먹선
├──────┴──────┴───────────────┤
│ (탭 내용만 스크롤)            │
└─────────────────────────────┘
│ 이 땅의 상세 페이지 →         │  ← 고정
└─────────────────────────────┘
```

탭 배분:

- **땅 정보** — 지목 · 면적 · 소재지 · 고유번호(PNU) · 공시지가 안내
- **시세** — 공시지가 5년 추이(연도 수 가변) · 지역 실거래 중앙값 + **필수 경고 문구**
- **주변** — 최근접 역(직선거리 주 표기) · 주변 시설(가장 가까운 하나의 거리) · 지역 뉴스(최하단, 비중 낮춤)

## 데이터 미연동 표기

데이터가 아직 없는 항목(B12·B13·B14)은 섹션 제목 옆에 `.badge`를 붙인다. 배지 없이 그럴듯한 수치를 노출하지 않는다.

```html
<span class="badge">표시 예시 · 좌표 연동 전</span>
<span class="badge">외부 API 연동 전</span>
```

## 품질 기준

- 데스크톱 전용. 1280px 미만에서는 레이아웃을 줄이지 않고 가로 스크롤한다
- 지도가 화면의 70% 이상을 차지한다
- 키보드 Tab 포커스 링 `outline: 2px solid var(--fg)`
- `prefers-reduced-motion` 존중
- 다크모드 구현하지 않음
- 애니메이션은 패널 페이드 · 버튼 1px 눌림 · 토스트 페이드 세 가지만
