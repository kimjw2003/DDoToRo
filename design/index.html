이번 설계에서 내린 결정

브리프가 열어둔 질문들에 대한 답이다. 되돌릴 근거가 있으면 말씀해 주세요.

상세 패널 구조 고정 요약 카드 + 3탭(땅 정보 · 시세 · 주변). 아코디언은 라벨이 모두 보이는 장점이 있으나 5개가 열리면 다시 세로 스크롤 문제로 돌아간다. 탭은 깊이를 3으로 묶어 어느 탭에서도 한 화면에 끝난다. 총액·지번·실루엣은 탭 밖에 고정해 어느 탭에 있어도 어느 땅인지 잃지 않는다.
패널 폭 320 → 384px, 1600px 이상에서 416px. 지목·면적 2열과 5년 차트가 320px에서는 눌린다. 지도 점유율은 여전히 70% 이상.
“색은 가격만” 원칙 유지한다. 신규 카테고리는 색이 아니라 1.7px 단선 아이콘으로 구분하고, 강조색은 가격 램프 최상단과 같은 벽돌 색족으로 묶어 화면의 색 이야기를 하나로 유지했다.
가격 램프 색 초록 → 점토·벽돌. 배경지도의 산림 초록과 램프가 같은 색상이라 축소 화면에서 섞였다.
지역 시세 표기 단위 평당을 앞에, ㎡당을 뒤에. z15 미만에서 읍면 12개 시세 칩을 지도에 직접 올려 “필지가 사라지는 빈 구간”을 채운다.
역 거리 표기 직선거리를 주 표기, 차 소요시간은 추정으로 병기. 경로 API 약관이 확인되기 전까지 도보 시간은 쓰지 않는다 — 산악 지형에서 오차가 크다.
뉴스 비중 ‘주변’ 탭 최하단, 바탕색을 한 단 낮춰 시각 비중을 내렸다.
화면 폭 정책 지도 화면은 최소 1280px, 그보다 좁으면 축소하지 않고 가로 스크롤한다. 1024px로 낮추면 패널을 빼고 지도가 640px밖에 안 남아 필지 클릭이 어려워진다. 단독 페이지만 예외 — 검색 유입이 목적이라 모바일 검색 트래픽이 들어오므로 깨지지 않을 정도의 폴백 한 블록을 남겼다. 모바일 UI를 설계한 것은 아니다.
최소 글자 크기 1차 지침이 선언한 14px 하한을 실제로 지켰다. 13px을 쓰던 단위·힌트를 전부 14px로 올렸다.

남은 결정 · 데이터

  1. 시세 추이 5년 → 10년. 원본 A16~A19로 5년은 적재 로직만 고치면 된다. 차트는 연도 수 가변을 전제로 그렸다.
  2. 지하철역 좌표. 양평군 내 경의중앙선 역이 10개 미만이라 직접 입력이 현실적이다. 경로 API 약관 확인 전까지 직선거리로 간다.
  3. 공공시설 카테고리. 시안은 초등학교·보건지소·마트·관공서·버스정류장 5종. 시골 땅에서는 개수가 아니라 가장 가까운 하나의 거리가 정보다.
  4. 뉴스 검색 키워드. 읍면 단위(“양평군 서종면 부동산”)가 군 단위보다 관련도가 높지만 결과 수가 급감한다. 군 단위 + 읍면 필터를 권한다.
  5. z15 미만 안내. 1차 방침대로 배너를 띄우지 않는다. 대신 읍면 시세 칩이 그 구간의 콘텐츠가 된다.
  6. 모바일은 보류. 데스크톱을 확정한 뒤 착수한다. 하단 시트 3단계 시안은 parked/map-mobile.html에 보관해 두었다.
