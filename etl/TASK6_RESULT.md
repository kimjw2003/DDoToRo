## `GET /api/search?q=`

지번과 지역명을 분리해 파싱한다. 마지막 토큰이 `245-7`, `산22` 형태면 지번으로 본다.

```
"서종면 245-7"       -> region "서종면"  jibun "245-7"    1건   263ms
"문호리 245"         -> region "문호리"  jibun "245"      1건    16ms
"양평읍"             -> region "양평읍"  jibun null      20건   212ms
"서종면 산22"        -> region "서종면"  jibun "산22"      5건    10ms
"없는동네 999-9"     -> 0건                                      9ms
```

- 지역 토큰은 `emd || ' ' || ri`에 대해 **모두 만족**해야 한다.
  `서종면 문호리 245`처럼 읍면과 리를 함께 줘도 걸린다
- 가격이 있는 필지를 먼저 보여준다. 정보가 없는 필지는 사용자가 할 일이 없다
- LIKE 패턴에서 `%`와 `_`는 와일드카드라 사용자 입력을 이스케이프한다
- 도로명주소는 MVP 범위 밖이다

## `/land/[pnu]` — SSR 상세 페이지

SEO가 목적이므로 **자바스크립트 없이도 내용이 전부 HTML로 나와야 한다.**
`curl`로 받은 HTML(=JS 미실행)에서 다음을 모두 확인했다.

```
✓ 양근리 448-8      ✓ 162억          ✓ 대(집터)
✓ 10,565㎡          ✓ 3,196평        ✓ 2026년 공시
✓ 229,585원/1,938건 ✓ 이 필지의 거래 기록이 아닙니다
```

```html
<title>경기 양평군 양평읍 양근리 448-8 공시지가 - DDoToRo</title>
<meta name="description" content="… 개별공시지가는 162억 9,081만원입니다.
      면적 10,565㎡ (3,196평), 지목 대(집터), ㎡당 1,542,000원.">
```

JSON-LD로 `Place` / `PostalAddress` / `GeoCoordinates` / `PropertyValue`를 넣었다.
없는 PNU는 404를 반환한다.

> 검증 시 주의: React SSR은 `{expr}text`를 `양평읍<!-- --> 최근 3년`처럼 렌더한다.
> 문자열을 통째로 grep하면 없는 것처럼 보이므로 조각으로 나눠 확인해야 한다.

## 처리한 문제

### 검색 결과를 effect에서 비우지 않는다

입력이 2글자 미만이 되면 `setHits(null)`을 호출하는 방식은
"effect 안에서 setState" 린트 규칙에 걸린다.

결과를 **검색어와 함께** 들고 있도록 바꿨다.

```ts
const [found, setFound] = useState<{ q: string; results: SearchHit[] } | null>(null);
const hits = found && found.q === term ? found.results : null;
```

입력이 바뀌는 순간 이전 결과가 저절로 무효가 되므로 따로 비울 필요가 없고,
검색어가 바뀐 뒤 늦게 도착한 응답이 화면에 남는 문제도 함께 사라진다.
